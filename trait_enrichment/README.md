# Trait and pathway enrichment

This folder groups enrichment and heritability analyses by method:

- [`fgsea/`](fgsea/README.md) contains RNA marker and ATAC gene-activity
  FGSEA scripts.
- [`ldsc_heritability/`](ldsc_heritability/README.md) contains trait input
  preparation, LDSC command generation, result summaries, and plots.

# Decision records

This directory contains rendered BrainVar/BrainVar2 evidence and manual decision
records explicitly approved for public release. Raw MBV reports, candidate-level
tables, sequencing files, and unrestricted review materials do not belong here.

## Joseph_022124 Brainvar2 Sample Matching - documenting.pdf

- Role: master documentation used by the working group to review BrainVar and
  BrainVar2 sample identities and pairing decisions.
- Contents: 212 slides covering the sample-identification problem, QTLtools MBV
  method, cohort-level findings, expected dataset rescue, and individual edge
  cases with non-synthetic comparison plots and written interpretations.
- Author metadata: Joe Lalli.
- Presentation date shown in the deck: 2024-02-21.
- PDF creation metadata: 2025-02-19 20:07:20 CST; modification metadata:
  2025-02-19 20:08:16 CST. These timestamps reflect a later PDF export.
- Format: tagged, optimized, unencrypted PDF 1.6; 10,051,768 bytes.
- Integrity: SHA-256 is recorded in `SHA256SUMS`.

The deck is the master review documentation, not a machine-readable final pairing
manifest. The PDF is retained byte-for-byte as supplied; plots were not extracted,
redrawn, or regenerated for the repository.

Additional approved figures may be added under `figures/`. Each addition should
identify the source analysis, what decision it supported, and whether it is an
original rendered output or an export from a review document.

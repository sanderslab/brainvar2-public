# sQTL

The STAR-WASP, LeafCutter clustering, phenotype preparation, and intron
annotation pipeline scripts are in [`scripts/`](scripts/). Additional sQTL
concatenation, liftover, munging, and sashimi plotting utilities are grouped
there as well. The LeafCutter source checkout is retained in [`leafcutter/`](leafcutter/).

See [`scripts/README.md`](scripts/README.md) for the pipeline steps and inputs.
